# Publicity for the University 🎓

*[العربية 🇪🇬 below / بالعربي في الأسفل](#عن-قسم-المكتبات-والوثائق-والمعلومات-)*

A single-page informational website built for the **Library, Documentation & Information Science Department** at Cairo University's Faculty of Arts, designed to guide prospective and new students through everything they need to know about the department.

🔗 **Live demo:** https://pluto6169.github.io/Publicity-for-the-University/

## About the Project

High school graduates and new students often struggle to find clear, organized information about academic departments before choosing their specialization. This project addresses that gap by presenting the LIS department's key information in one accessible, easy-to-navigate page.

## Features

- 📖 **Department History** — origins, academic development, partnerships, and vision
- 🎯 **Academic Tracks** — overview of the department's specializations (Library Management, Information Systems, Digital Information, Archives & Documents Management, Data Analysis, and more)
- ✅ **Admission Requirements** — required documents, exams, and the branching system after year one
- 🎓 **Postgraduate Studies** — Master's and PhD program requirements
- 💼 **Career Opportunities & Salary Benchmarks** — common job titles and approximate salary ranges for graduates
- 📅 **Conferences & Activities** — academic conferences, workshops, and student activities
- 🌓 **Light / Dark Mode** — toggle between themes for comfortable reading
- 📱 **Responsive Design** — works smoothly across desktop and mobile

## Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — styling and responsive layout
- **JavaScript** — theme toggle and interactive navigation

## Getting Started

To run the project locally:

```bash
git clone https://github.com/pluto6169/Publicity-for-the-University.git
cd Publicity-for-the-University
```

Then simply open `index.html` in your browser — no build step or dependencies required.

# التعريف بقسم المكتبات والوثائق والمعلومات 🎓

موقع من صفحة واحدة تم بناؤه لـ **قسم المكتبات والوثائق والمعلومات** بكلية الآداب، جامعة القاهرة، بهدف مساعدة الطلاب الجدد والمقبلين على القسم على معرفة كل ما يحتاجونه عنه.

🔗 **رابط الموقع:** https://pluto6169.github.io/Publicity-for-the-University/

## عن المشروع

غالبًا ما يواجه خريجو الثانوية العامة والطلاب الجدد صعوبة في إيجاد معلومات واضحة ومنظمة عن الأقسام الأكاديمية قبل اختيار تخصصهم. يعالج هذا المشروع هذه المشكلة من خلال عرض أهم معلومات القسم في صفحة واحدة سهلة التصفح.

## المميزات

- 📖 **تاريخ القسم** — النشأة، التطور الأكاديمي، الشراكات، والرسالة والرؤية
- 🎯 **التخصصات الأكاديمية** — نظرة عامة على تخصصات القسم (إدارة المكتبات، نظم المعلومات، المعلومات الرقمية، إدارة الوثائق والأرشيفات، تحليل المعلومات، وغيرها)
- ✅ **متطلبات القبول** — المستندات المطلوبة، الاختبارات، ونظام التشعيب بعد السنة الأولى
- 🎓 **الدراسات العليا** — متطلبات برامج الماجستير والدكتوراه
- 💼 **فرص العمل ومتوسط المرتبات** — أبرز المسميات الوظيفية ومتوسط الرواتب التقريبي للخريجين
- 📅 **المؤتمرات والأنشطة** — المؤتمرات العلمية وورش العمل والأنشطة الطلابية
- 🌓 **الوضع الفاتح / الغامق** — إمكانية التبديل بين الوضعين لتجربة قراءة مريحة
- 📱 **تصميم متجاوب** — يعمل بسلاسة على أجهزة الكمبيوتر والهواتف

## التقنيات المستخدمة

- **HTML5** — بنية الصفحة
- **CSS3** — التنسيق والتصميم المتجاوب
- **JavaScript** — خاصية تبديل الوضع والتنقل التفاعلي
